# Olawale Israel — Portfolio

Modern React/Vite portfolio for Olawale Israel, Full-Stack Blockchain Developer.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```bash
npm run build
```

The production output is generated in `dist/` and can be deployed to Vercel.
